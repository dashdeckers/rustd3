# rustd3-core

The d3 port behind [rustd3](https://crates.io/crates/rustd3): scales,
ticks, axes, shapes and `PathContext`, number and time formats, locales,
color and schemes, interpolation and easing, array statistics, recordings
of sampled data, and zoom, brush, drag and animation as plain values and
state machines, renderer-agnostic and graded by d3's own tests.

Most applications depend on the `rustd3` facade, whose README is the
guide; the API is documented on [docs.rs](https://docs.rs/rustd3-core).
