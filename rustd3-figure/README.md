# rustd3-figure

The figure layer of [rustd3](https://crates.io/crates/rustd3): a
`Figure` of panels, marks, axes, legends and colorbars, laid out from
text measured with typst and drawn into one drawing list that renders as
SVG, and as PNG, GIF and PDF behind features.

Most applications use it through the `rustd3` facade's `figure` feature
(`rustd3::figure`), whose README is the guide; the API and the features
are documented on [docs.rs](https://docs.rs/rustd3-figure).
