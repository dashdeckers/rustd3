# rustd3-fonts

DejaVu Sans and DejaVu Sans Mono, regular and bold each, and New
Computer Modern Math, bundled so that
[rustd3](https://crates.io/crates/rustd3)'s figures render the same on
every machine. rustd3-figure uses them through its default `fonts`
feature.

The crate's code is MIT OR Apache-2.0; the fonts keep their own licences
(Bitstream Vera with the Arev terms, and the GUST Font License), in
`LICENSE`. Documentation: [docs.rs](https://docs.rs/rustd3-fonts).
